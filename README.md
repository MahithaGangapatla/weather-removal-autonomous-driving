# Real-Time Weather Removal Using GANs for Robust Road Object Detection in Autonomous Driving

## Internship Details
- Organization: Indian Institute of Technology Tirupati (IIT Tirupati)
- Role: Research Intern
- Duration: Summer Internship 2025

## Project Overview
This project focuses on removing adverse weather effects such as rain, fog, and snow from road images to improve object detection performance in autonomous driving systems.

## Techniques Used
- OpenCV for rain removal
- Dark Channel Prior for fog removal
- Pix2Pix GAN for snow removal
- DETR for object detection

## Technologies
- Python
- OpenCV
- PyTorch
- NumPy
- Matplotlib
